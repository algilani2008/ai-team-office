# مكتبي الافتراضي — فريق الذكاء الاصطناعي (AI Team Office)

مشروع "مكتب افتراضي" تفاعلي بالعربي يحاكي فريق موظفين ذكاء اصطناعي حقيقيين، يشتغلون على ChatGPT وGemini وClaude، مرتبط بمشروع تسويقي حقيقي "المحلل الرقمي".

## الملفات
- `index.html` — الصفحة الكاملة (HTML/CSS/JS) — ملف واحد ذاتي الاحتواء، يعمل مباشرة في أي متصفح أو كـ GitHub Pages.

## النسخة الحية
منشور أصلاً كـ Claude Artifact: https://claude.ai/artifact/29LTtaPiKVCHwPrK1xmpZa

## أهم المزايا
- موظفون بشخصيات وتخصصات واقعية، مقسّمين على 8 أقسام.
- تفويض مهام حقيقي بين الموظفين (delegate_task) مع تسلسل إداري متعدد المستويات.
- توظيف موظفين جدد فعلياً من داخل المكتب (hire_employee، عبر نور).
- ربط اختياري بخوادم ChatGPT/Gemini حقيقية عبر Cloudflare Worker proxy (كل موظف له إعدادات اتصال خاصة).
- لوحة مهام، اجتماعات، أرشيف، وملفات مشاريع فعلية قابلة للتنزيل.

## التطوير
أي تعديل على `index.html` يحتاج نشره بعدين للنسخة الحية (Claude Artifact) ليصير فعّال فوراً للمستخدمين.
