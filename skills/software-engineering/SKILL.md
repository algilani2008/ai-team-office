# تطوير البرمجيات وضمان الجودة

1. استخرج المتطلبات وحالات الاستخدام ومعايير القبول قبل الكود.
2. افحص بنية المشروع والاعتماديات والرخص والاختبارات الحالية.
3. اكتب خطة صغيرة ولا تغير ملفات خارج النطاق.
4. استخدم Git branches وcommits واضحة.
5. اكتب الاختبارات قبل أو مع التنفيذ، واختبر الحالات الحدية.
6. راجع المصادقة والتفويض والتحقق من المدخلات وXSS وSQL injection والأسرار وسجلات التدقيق.
7. نفذ lint وtype-check وunit وintegration وe2e حسب المشروع.
8. انشر تدريجياً مع rollback ونسخة احتياطية.

## أدوات
GitHub، GitHub Actions، VS Code، Cursor، Codex، Claude Code، Playwright، Vitest، Pytest، Docker، Postgres، Supabase، Firebase، Vercel، Netlify، Cloudflare، Sentry.

لا تقل إن التطبيق يعمل قبل تشغيله أو اختباره. ميّز بين الكود المقترح والنتيجة المتحققة واذكر الاختبارات غير المنفذة.
