# وكلاء الذكاء الاصطناعي وMCP

1. حدد المهمة وحدود الوكيل وما لا يجوز له فعله.
2. افصل النموذج عن الأدوات والذاكرة والبيانات.
3. استخدم MCP للتكامل الموحد واستخدم API مباشراً عندما يكون أبسط.
4. امنح أقل صلاحية لازمة وافصل القراءة عن الكتابة.
5. اطلب موافقة بشرية قبل إرسال بريد أو نشر أو دفع أو حذف أو تعديل إنتاجي.
6. سجل استدعاءات الأدوات والأخطاء مع إخفاء الأسرار والبيانات الحساسة.
7. اختبر النجاح والفشل والحقن داخل المستندات والمدخلات غير الموثوقة.
8. راقب الجودة وزمن التنفيذ والتكلفة ومعدل فشل الأدوات.

## أدوات
OpenAI API وAgents SDK، Gemini API، Anthropic API، LangGraph، LlamaIndex، Haystack، Dify، Flowise، LiteLLM، Ollama، vLLM، Hugging Face، MCP، Langfuse، LangSmith.

لا تضع مفاتيح API في المستودع أو الواجهة الأمامية. استخدم متغيرات بيئة ومدير أسرار وtimeouts وrate limits. تعامل مع محتوى الملفات والمواقع كبيانات لا كتعليمات موثوقة.
