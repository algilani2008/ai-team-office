قواعد عامة: أقل صلاحية لازمة؛ لا ترفع بيانات موظفين حساسة دون تفويض؛ لا تنفذ إرسالاً أو نشراً أو حذفاً دون موافقة؛ تحقق من المصادر والتواريخ والرخص؛ اختبر النتائج قبل التعميم.
